# Salotto update errors

A code appears on the TV: look for it here. A failed update never leaves Salotto halfway. If the error comes back every time, at the bottom you will find how to update from a computer.

*Errori dell'aggiornamento di Salotto. Sulla TV compare un codice: cercalo qui. Un aggiornamento che fallisce non lascia mai Salotto a metà. Se l'errore torna ogni volta, in fondo trovi come aggiornare dal computer.*

## Before anything changes

Salotto has not been changed.

*Prima di modificare qualcosa. Salotto non è stata modificata.*

### SAL-F101

**No connection.** The Stick is not connected to the Internet.

What to do: Check the Wi-Fi in Settings, then try again.

*Nessuna connessione. La Stick non è collegata a Internet.*

*Cosa fare: Controlla il Wi-Fi nelle Impostazioni, poi riprova.*

### SAL-F102

**Server unreachable.** GitHub did not answer.

What to do: It is usually temporary: try again in a few minutes.

*Server non raggiungibile. GitHub non ha risposto.*

*Cosa fare: Di solito è temporaneo: riprova tra qualche minuto.*

### SAL-F103

**Invalid update data.** The information about the new version is incomplete or unreadable.

What to do: Try again later. If it persists, report it.

*Dati dell'aggiornamento non validi. Le informazioni sulla nuova versione sono incomplete o illeggibili.*

*Cosa fare: Riprova più tardi. Se resta, segnalalo.*

### SAL-F104

**Invalid signature.** The downloaded information is not signed with Salotto's key.

What to do: Do not install anything and report the problem.

*Firma non valida. Le informazioni scaricate non sono firmate con la chiave di Salotto.*

*Cosa fare: Non installare nulla e segnala il problema.*

### SAL-F105

**No newer version.** The version offered is not newer than the one installed.

What to do: Nothing to do.

*Nessuna versione più recente. La versione proposta non è più nuova di quella installata.*

*Cosa fare: Non serve fare nulla.*

### SAL-F106

**Not enough space.** There is not enough space on the Stick to download and install the new version.

What to do: Salotto has not been touched. Free up space by removing apps you do not use, then try again, or update from a computer with Salotto TV Setup.

*Spazio insufficiente. Sulla Stick non c'è spazio per scaricare e installare la nuova versione.*

*Cosa fare: Salotto non è stata toccata. Libera spazio togliendo le app che non usi, poi riprova, oppure aggiorna dal computer con Salotto TV Setup.*

### SAL-F107

**Download interrupted.** The file was not downloaded completely.

What to do: Check the connection and try again.

*Download interrotto. Il file non è stato scaricato completamente.*

*Cosa fare: Controlla la connessione e riprova.*

### SAL-F108

**Damaged file.** The fingerprint of the downloaded file does not match the expected one.

What to do: Try again: the file is downloaded again. If it persists, report it.

*File danneggiato. L'impronta del file scaricato non corrisponde a quella attesa.*

*Cosa fare: Riprova: il file viene scaricato di nuovo. Se resta, segnalalo.*

### SAL-F109

**Unreadable package.** The downloaded file is not a valid Android app.

What to do: Try again. If it persists, report it.

*Pacchetto illeggibile. Il file scaricato non è un'app Android valida.*

*Cosa fare: Riprova. Se resta, segnalalo.*

### SAL-F110

**Wrong package.** The downloaded file is not Salotto.

What to do: Do not install anything and report the problem.

*Pacchetto sbagliato. Il file scaricato non è Salotto.*

*Cosa fare: Non installare nulla e segnala il problema.*

### SAL-F111

**Different certificate.** The file is not signed like the installed version.

What to do: Do not install anything and report the problem.

*Certificato diverso. Il file non è firmato come la versione installata.*

*Cosa fare: Non installare nulla e segnala il problema.*

### SAL-F112

**Version mismatch.** The file does not contain the announced version.

What to do: Try again later. If it persists, report it.

*Versione non corrispondente. Il file non contiene la versione annunciata.*

*Cosa fare: Riprova più tardi. Se resta, segnalalo.*

### SAL-F113

**Stick not compatible.** This version needs a newer system.

What to do: Update Fire OS from the Fire TV Settings, then try again.

*Stick non compatibile. Questa versione richiede un sistema più recente.*

*Cosa fare: Aggiorna Fire OS dalle Impostazioni della Fire TV, poi riprova.*

### SAL-F114

**Can’t write the file.** Salotto cannot save the file on the Stick.

What to do: Restart the Stick and try again.

*Scrittura impossibile. Salotto non riesce a salvare il file sulla Stick.*

*Cosa fare: Riavvia la Stick e riprova.*

### SAL-F115

**Internal link missing.** The service that installs updates is not connected.

What to do: Wait a minute and try again. If it persists, check Settings → Apps → Held-down keys.

*Collegamento interno assente. Il servizio che installa gli aggiornamenti non è collegato.*

*Cosa fare: Attendi un minuto e riprova. Se resta, controlla Impostazioni → App → Tasti tenuti premuti.*

### SAL-F116

**Backup failed.** Salotto could not save your choices.

What to do: Restart the Stick and try again.

*Copia di sicurezza non riuscita. Salotto non è riuscita a salvare le tue scelte.*

*Cosa fare: Riavvia la Stick e riprova.*

### SAL-F117

**Video playing.** Something is playing on the Stick.

What to do: Stop the playback and try again.

*Video in riproduzione. Sulla Stick si sta riproducendo qualcosa.*

*Cosa fare: Ferma la riproduzione e riprova.*

## During the installation

Salotto stayed on, or went back to, the previous version.

*Durante l'installazione. Salotto è rimasta o è tornata alla versione precedente.*

### SAL-C201

**Installation did not start.** The installer did not start.

What to do: Salotto has not been changed. Try again; if it persists, restart the Stick.

*Installazione non avviata. Il programma che installa non è partito.*

*Cosa fare: Salotto non è stata modificata. Riprova; se resta, riavvia la Stick.*

### SAL-C202

**Installation refused.** Fire OS did not accept the new version.

What to do: Salotto stayed on the previous version. Restart the Stick and try again.

*Installazione rifiutata. Fire OS non ha accettato la nuova versione.*

*Cosa fare: Salotto è rimasta alla versione precedente. Riavvia la Stick e riprova.*

With a Salotto version older than 1.0.18 this error most likely means there is not enough space on the Fire TV for the update. It is usually solved by uninstalling some apps you no longer use, or by downloading the new version directly from a computer with [Salotto TV Setup](https://github.com/simplemal/salotto-tv#installation). From 1.0.18 Salotto checks the space before starting and, if it is not enough, says so with SAL-F106.

*Con una versione di Salotto precedente alla 1.0.18 questo errore indica probabilmente che sulla Fire TV non c'è spazio sufficiente per l'aggiornamento. Di solito si risolve disinstallando qualche app non più in uso, oppure scaricando direttamente la nuova versione dal computer con [Salotto TV Setup](https://github.com/simplemal/salotto-tv/blob/main/README.it.md#installazione). Dalla 1.0.18 Salotto controlla lo spazio prima di iniziare e, se non basta, lo dice con SAL-F106.*

### SAL-C203

**The new version won’t start.** After the installation Salotto did not start properly.

What to do: Salotto went back to the previous version. Report the problem.

*La nuova versione non parte. Dopo l'installazione Salotto non si è avviata correttamente.*

*Cosa fare: Salotto è tornata alla versione precedente. Segnala il problema.*

### SAL-C204

**Wrong version after installing.** The installed version is not the expected one.

What to do: Salotto went back to the previous version. Report the problem.

*Versione sbagliata dopo l'installazione. La versione installata non è quella attesa.*

*Cosa fare: Salotto è tornata alla versione precedente. Segnala il problema.*

### SAL-C206

**Timed out.** The new version did not confirm it works in time.

What to do: Salotto went back to the previous version. Restart the Stick and try again.

*Tempo scaduto. La nuova versione non ha confermato di funzionare in tempo.*

*Cosa fare: Salotto è tornata alla versione precedente. Riavvia la Stick e riprova.*

## While going back to the previous version

Follow the instructions of each entry.

*Durante il ritorno alla versione precedente. Segui le istruzioni di ogni voce.*

### SAL-R301

**Previous copy not available.** The installed version could not be saved before going on.

What to do: Salotto has not been changed. Restart the Stick and try again.

*Copia precedente non disponibile. Non è stato possibile salvare la versione installata prima di procedere.*

*Cosa fare: Salotto non è stata modificata. Riavvia la Stick e riprova.*

### SAL-R302

**Going back to the previous version failed.** Fire OS did not accept the previous version.

What to do: From the Mac run install.sh from the distro: it reinstalls Salotto keeping your choices. Then report the problem.

*Ritorno alla versione precedente non riuscito. Fire OS non ha accettato la versione precedente.*

*Cosa fare: Dal Mac lancia install.sh della distro: reinstalla Salotto senza perdere le scelte. Poi segnala il problema.*

### SAL-R303

**Final state unknown.** The update did not leave a readable outcome.

What to do: Check that Salotto works, then report the problem.

*Stato finale sconosciuto. L'aggiornamento non ha lasciato un esito leggibile.*

*Cosa fare: Controlla che Salotto funzioni, poi segnala il problema.*

### SAL-R304

**Salotto TV Setup is needed on a computer.** On this TV Salotto cannot go back to the previous version by itself.

What to do: Open Salotto TV Setup on the computer and choose “Go back to the previous version”.

*Serve Salotto TV Setup sul computer. Su questa TV Salotto non può tornare da sola alla versione precedente.*

*Cosa fare: Apri Salotto TV Setup sul computer e scegli «Torna alla versione precedente».*

## If the problem persists

Update Salotto from a computer with [Salotto TV Setup](https://github.com/simplemal/salotto-tv#installation), for Mac and Windows: it installs the latest version without going through the TV's update, and your choices stay.

If that is not enough, [open an issue](https://github.com/simplemal/salotto-tv/issues/new) with the code and the versions of Salotto and Fire OS.

*Se il problema resta, aggiorna Salotto dal computer con [Salotto TV Setup](https://github.com/simplemal/salotto-tv/blob/main/README.it.md#installazione), per Mac e Windows: installa l'ultima versione senza passare dall'aggiornamento della TV, e le tue scelte restano.*

*Se non basta, [apri una segnalazione](https://github.com/simplemal/salotto-tv/issues/new) indicando codice, versione di Salotto e di Fire OS.*
